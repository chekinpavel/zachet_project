# Zachet Project

## 📌 Описание проекта
Этот проект содержит базу данных и каркас веб-приложения для работы с пользователями, ролями, материалами и партнёрами.

## 🏗 Структура проекта
📂 `database/` – SQL-скрипты  
📂 `src/` – Исходный код приложения (Flask API + SQLAlchemy)  
📂 `tests/` – Тесты  

## 🚀 Как запустить
1. Установите зависимости:
   ```sh
   pip install flask flask_sqlalchemy pymysql
   ```
2. Запустите сервер:
   ```sh
   python src/app.py
   ```

## 📊 База данных
Структура БД находится в `database/schema.sql`.
